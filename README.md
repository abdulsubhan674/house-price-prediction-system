# House Price Prediction System

## Overview
This project is a Machine Learning-based House Price Prediction System developed using Python and Scikit-learn.

The project predicts housing prices using data preprocessing, exploratory data analysis, feature scaling, PCA, and multiple machine learning algorithms.

---

## Features
- Data preprocessing
- Exploratory Data Analysis (EDA)
- PCA dimensionality reduction
- Model training & evaluation
- Visualization using Matplotlib & Seaborn

---

## Algorithms Used
- Decision Tree
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Artificial Neural Network (ANN)
- Naïve Bayes
- Ensemble Learning

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook
